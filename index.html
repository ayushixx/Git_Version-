Object-Oriented Architecture of MiniGit

How modern C++ Object-Oriented Programming (OOP) transforms low-level file I/O and cryptographic hashing into an extensible, robust version control system.

Encapsulation & Immutability
class

FileObject

Encapsulates file data, filename, and content-addressable hashing. Private members prevent mutation after instantiation.

private: string filename; string content; string hash;
public: FileObject(const string& name, const string& data); static string makeHash(const string& data); // FNV-1a bool save(const fs::path& objectsDirectory) const;
Key OOP Principle: Content-Addressable Storage (CAS) ensures that two identical file contents always yield the same hash, deduplicating storage in .minigit/objects/.
Abstraction & Serialization
class

Commit

Models a point-in-time immutable snapshot of the repository, binding commit metadata, timestamps, and staged file references.

private: string id; string message; string timestamp; vector<StagedFile> files;
public: Commit(id, message, time, files); bool save(const fs::path& dir) const; void display() const;
Key OOP Principle: Snapshot Separation. The Commit object treats the StagedFile list as an immutable record serialized into <id>.commit.
Facade Pattern & State Manager
class

Repository

Serves as the high-level Facade encapsulating the file-system state, index parsing, staging table, and disk commits.

private: const fs::path root = ".minigit"; bool loadIndex(); bool saveIndex() const; static string currentTime();
public: bool init(); bool addFile(const string& filename); bool commitChanges(const string& message); bool showHistory() const;
Key OOP Principle: Facade & Information Hiding. Callers interact with simple verbs without knowing how std::filesystem or atomic index updates happen.
Polymorphism & Command Pattern
abstract class

Command <Polymorphic>

Decouples CLI input parsing in main() from execution logic using dynamic dispatch and virtual functions.

public: virtual bool execute(Repository&, const vector<string>&) = 0; virtual ~Command() = default;
InitCommand AddCommand CommitCommand LogCommand
Key OOP Principle: Open/Closed Principle (OCP). Adding new commands (like branch, checkout, or diff) requires zero modifications to existing command classes.
